Two lanes off one database

Lane A · Backup set

A full restore of the CDK backup into an environment the dealer controls, then delta-only refreshes. It exposes structure the API never will — table inventory, keys, code tables, the application dictionary itself. Complete, trusted, lagging.

Lane B · Fortellis API

OAuth 2.0 against CDK Drive, on the platform's own Setup → Bulk → Delta pattern. Current, partial, entitlement-bound. The ledger cannot be reached here at all: chart of accounts, accounting schedules, department master, vendor master, warranty claim, purchase and receipt are all unavailable on Fortellis and can only come from Lane A or a file export.

Delta refresh

Seed once, then refresh only what changed. A refresh job's cost must be proportional to the volume of change, never to the size of the database. Native delta where CDK exposes one; a three-tier utility of our own where it does not.

Data mart library

Structure harvested from the application's own metadata rather than hand-drawn, then shaped to the SAP model — MARA, MARC, MARD, MBEW, MATDOC, MVKE and the FI/CO analogues — so a PACCAR SAP payload maps one to one and the dealer's model outlives any DMS vendor. Blanks in the API-derived structure are filled from Lane A.

reconcile()

An executable function, called on demand rather than run on a timer. The API may overwrite a backup value within its authoritative scope, never silently; a later change showing variance against what was previously reconciled is logged as an exception rather than quietly winning.

The 20 Group surface, and the work list

One dashboard, and two prioritised lists — one by urgency, one by strategy, deliberately not merged. A click composes a draft email; nothing is sent, and nothing is written back to CDK. Work is still entered by hand, exactly as it is today.

Why the backup, and not the system

  • No production risk and no change to a running dealership.
  • No integration window to negotiate.
  • The replica is repeatable and disposable, so the build can be re-run from scratch.
  • Until Tim's agreement is executed, the same pipeline runs on synthetic and mock data without changing shape.

Gates — real data does not move until

  • Tim's agreement is executed. Until then, synthetic dashboards and the mock composite stand in.
  • Luke has 20-Group access. Variance fields stay blank rather than guessed.
  • Call history ingests through a Peterbilt-owned TELUS service account, never personal credentials.
  • Signed user agreements and public access URLs exist for the systems in Craig Allen's 16-system register.
  • The public / protected repository split holds: client-facing material stays separate from the protected origin thesis.
