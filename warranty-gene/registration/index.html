Warranty GENE

Registration & Terms

PRWS on Fortellis · PSSM Decisiv OWL / VIP · PACCAR Connect · PACCAR Powertrain T&Cs · NHTSA.

Two questions, two answers. First, how the twin gathers warranty registration per VIN — retail sale date, in-service date, PDI status, coverage codes sold with the chassis. Second, how it gathers terms and conditions — the months, miles, hours, and exclusions that apply to that chassis — from a machine-readable API rather than by interpreting a contract PDF.

Read the inventory PDF registration-and-terms.json

Registration surfaces

PRWS on Fortellis — record of truth observed

Machine-readable REST API at api.fortellis.io. OpenAPI 2.0 / 3.0. Subscription-Id header, OAuth2 service-account credential. Returns per-VIN registration, PDI status, retail-sale date, claim drafts, and SIR Sheet Access. CDK Global confirmed: "PRWS is now available on Fortellis."

PSSM (Decisiv OWL / VIP) — point of service observed

Case-scoped coverage read-back and truck-spec build data through the DMS integration (CDK Drive, Karmak, Procede Excede, SERTI). OWL returns warranty coverage; VIP returns spec data. Not a public REST API — reached from the DMS side.

PACCAR Connect — telemetry API inferred

DAF-branded, described in PACCAR literature as "our secure interface API." Partner onboarding required. Third-party integrators (Navixy) claim Kenworth and Peterbilt coverage; the DAF-branded page does not itself name Peterbilt. Pending PACCAR North America confirmation for Hawkins.

PACCAR Solutions Portal & SIR through PRWS observed

Solutions Portal is a read-only telemetry UI (no API); use PACCAR Connect for structured downstream reads. SIR content flows out through PRWS on Fortellis via SIR Sheet Access, confirmed by Procede's v1.2 release notes.

Terms-and-conditions surfaces

PACCAR Powertrain product pages — canonical T&C table observed

Public, structured HTML at paccarpowertrain.com/products/{engine}/. Returns base engine, major components, base emissions (EPA vs CARB), and towing coverage in months / miles / km / hours. No auth, no partner requirement — the coverage math the twin needs is a compact table, not a contract.

MX Extended Warranty controlled PDF observed

The extended-plan matrix — PACCAR Protection, Aftertreatment, Major Component, Towing, base emissions — parsed at ingest into JSON. Published on PACCAR Powertrain Resources.

NHTSA Emission Service Bulletins — government cross-reference observed

Trust level 3 PDFs at static.nhtsa.gov/odi/tsbs/. Republishes the exact federal emissions coverage numbers — 10 years / 435,000 mi / 22,000 engine hours from the original warranty registration date for EMY2023 MX-11 and MX-13.

Peterbilt Warranty Procedure Manual & Quick Reference Guide observed

Dealer-distribution PDF and XLSX, held in the workspace. Coverage-window anchors, option-code-specific T&Cs (like the 7/700 ESA reimbursement tiers), and prior-approval flags. Companion to the T&C tables, not a replacement.

Non-movement covenant

Registration reads land in Hawkins-owned Azure Postgres and are never syndicated. T&C tables and coverage-duration data are non-confidential public T&Cs and may be cached in the twin's data layer alongside the schema. No customer PII enters the mapping documents in this public repository.
