How this works
  1. Fill in the fields below.
  2. Click Encrypt — encryption happens in this browser using the repo's age public key. Nothing leaves this page unencrypted.
  3. Copy the encrypted blob.
  4. Paste it into Store credentials workflow and hit Run workflow. The worker writes it to warranty-gene/dms-pull/credentials.age.
  5. Dispatch Pull VIN workflow with a test VIN. Output lands in warranty-gene/dms-pull/pulls/.
