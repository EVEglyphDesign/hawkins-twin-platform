Warranty GENE — Sidecar Blueprint

Modular plugin. Integral to the Hawkins Twin. Subscription for every other dealer.

This blueprint follows the Epiq Revenue Leakage — Document B architecture pattern, retargeted from post-commitment order edits to post-commitment warranty coverage. Same spine — Source adapter → Reasoning → Delivery → Observability — set on Peterbilt Atlantic's next four weeks of service bookings.

Read the blueprint (PDF, 10 pp.) Read the source (Markdown) Open the wireframe

What the blueprint covers

  • §1 The mandate — take a VIN, return whether the work about to be invoiced is covered, and rank the recovery opportunity across a cohort.
  • §2 The four-part architecture — source adapter, reasoning, delivery, observability. Live vs. configured for Peterbilt Atlantic.
  • §3 How it reasons — the six-step deterministic path and why every answer is auditable.
  • §4 What is already built — schema, ledger, mappings, wireframe, canon PDFs, and the lessons paid for once.
  • §5 Where the data lives — read live from NHTSA + PACCAR + DMS, compute in the browser tab, no persistent store.
  • §6 Pointing at a new dealer — five configuration items, three self-serve, two need an invitation from the dealer principal.
  • §7 The delivery surfaces — single VIN, work-order uplift, VIN batch scan. Same engine, three roles.
  • §8 How this scales — three subscription tiers: public-ledger, dealer-authorized, twin-integrated (Hawkins tier).
  • §9 Strategic frame — the industry-specific customer-and-equipment record repository the twin is building underneath.
  • §10 What is not in this blueprint — cross-brand support, write-back to PRWS, PII policy, claim submission automation.
  • §11 Provenance — every claim traceable to a URL that verifies 200 or a named dealer document.
