# Warranty GENE — dealer records

One file per VIN, filename is the VIN, one commit per change.
This is the Ring 2 subtree of the Warranty GENE architecture — dealer-scoped equipment records.

**Canon rule (EgD-WGB-002).** The VIN is the base code for every equipment record in this system and every downstream ring. Filename is the VIN. Directory anchor is the VIN. The identifier that survives every ring boundary is the VIN. No DMS record number. No dealer-internal serial.

## Layout

```
peterbilt-atlantic/
├── R00-sample/           ← seven committed sample records, exercise every schema branch
│   └── vins/{VIN}.json
├── R01-halifax/          ← empty; filled from DMS/PRWS/PSSM extract when credentials arrive
│   ├── vins/{VIN}.json
│   ├── work-orders/{YYYY-MM}/{WO-id}.json    ← join to VIN by `vin` field, never nested
│   └── bookings/{YYYY-Www}.json
├── R02-moncton/ … R08-yarmouth/
indexes/                  ← generated by scripts/build_indexes.py, never hand-edited
scripts/
├── validate_records.py   ← JSON Schema round-trip + filename-matches-VIN
├── build_indexes.py      ← emits the five indexes
├── test_indexing.py      ← round-trip: every primary VIN appears in every index it should
└── measure_repo_size.py  ← current footprint + projection
```

## The five indexes

| File | Key structure | Value |
| --- | --- | --- |
| `by-model.json` | `{model}` | list of VINs |
| `by-engine-series.json` | `{series}` | list of VINs |
| `by-coverage-expiry.json` | `{bucket}.{tier}` | list of VINs — tiers are `expired`, `critical` (≤3 mo), `soon` (≤12 mo), `healthy`, `n_a`, `unknown` |
| `by-in-service-month.json` | `{YYYY-MM}` | list of VINs |
| `open-jobs.json` | `{coverage_bucket}` | list of `{vin, job_id, type, ata_code, customer_pay_at_risk_cad, status}` |

Every index value is either a list of VINs or a list of objects keyed on `vin`. Never anything else.

## Running the scripts locally

```bash
pip install jsonschema
python warranty-gene/dealer-records/scripts/validate_records.py
python warranty-gene/dealer-records/scripts/build_indexes.py
python warranty-gene/dealer-records/scripts/test_indexing.py
python warranty-gene/dealer-records/scripts/measure_repo_size.py > warranty-gene/dealer-records/MEASURED-SIZE.md
```

CI runs all four on every push that touches `warranty-gene/dealer-records/**` or `warranty-gene/schema/**` — see [.github/workflows/warranty-gene-dealer-records.yml](../../.github/workflows/warranty-gene-dealer-records.yml).

## Adding real records

Real DMS/PRWS/PSSM extracts populate the same JSON shape as `R00-sample/vins/*.json`. Every credential-gated field carries a `source_provenance` entry naming the source system and capture timestamp. Fields that are still pending an upstream credential are marked `null` with `source_provenance` set to `pending — {source}`.

One commit per VIN change. Never batch multiple VINs into one commit — that erases the audit trail.
